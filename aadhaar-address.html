Aadhaar में Address कैसे Change करें?
शुरू करने से पहले: Aadhaar में registered mobile number उपलब्ध रखें। Online update के लिए UIDAI द्वारा स्वीकार किया गया valid Proof of Address (POA) चाहिए हो सकता है। Accepted documents, charges और process समय के साथ बदल सकते हैं, इसलिए final request से पहले UIDAI की official जानकारी जरूर देखें।

Step 1 — जरूरी चीजें तैयार रखें

  • Aadhaar number
  • Aadhaar से registered mobile number
  • UIDAI द्वारा accepted Proof of Address (POA)
  • Document की साफ scan/photo, यदि online upload मांगा जाए
  • OTP प्राप्त करने के लिए mobile चालू रखें

Step 2 — Official MyAadhaar Portal खोलें

केवल UIDAI के official MyAadhaar portal से service शुरू करें। किसी अनजान website पर Aadhaar number, OTP या documents न दें।

Official MyAadhaar खोलें

Step 3 — Aadhaar से Login करें

Aadhaar number दर्ज करें और registered mobile पर प्राप्त OTP से login करें। OTP किसी दूसरे व्यक्ति के साथ share न करें।

Step 4 — Address Update Service चुनें

MyAadhaar में available Aadhaar update service में Address Update का विकल्प चुनें। अगर online address update option उपलब्ध न हो, तो नीचे दिए offline centre वाले तरीके का उपयोग करें।

Step 5 — नया Address भरें

नया पता सावधानी से भरें। House/Building, Street/Locality, Village/Town/City, District, State और PIN Code जैसी fields को अपने Proof of Address के अनुसार रखें। Submit करने से पहले spelling और PIN code दोबारा check करें।

Step 6 — Address Proof लगाएँ

UIDAI की current list में accepted Proof of Address में से applicable document चुनें। Document की जानकारी और आवेदन में दिया address आपस में match होना चाहिए।

Step 7 — Preview करके Check करें

Final submission से पहले पूरा address और बाकी details ध्यान से पढ़ें। गलती हो तो submit करने से पहले सुधारें।

Step 8 — Submit करें

Portal पर दिखाई देने वाले instructions के अनुसार request submit करें और यदि उस समय कोई applicable fee/payment मांगी जाए तो official portal पर ही करें।

Step 9 — Request Number सुरक्षित रखें

Submission के बाद मिलने वाला acknowledgement/reference या Service Request Number (SRN) note करके रखें। इससे request का status देखने में मदद मिलती है।

Step 10 — Status Check करें

MyAadhaar की available status service में reference/SRN details से request का status check करें। Update complete होने पर Aadhaar details verify करें।

🏢 Offline Address Change

अगर online service उपलब्ध नहीं है या आप centre से update कराना चाहते हैं, तो Aadhaar Enrolment/Update Centre जाएँ। Aadhaar और आवश्यक original supporting documents साथ रखें। Centre पर operator द्वारा मांगी गई प्रक्रिया पूरी करें और acknowledgement slip सुरक्षित रखें।
